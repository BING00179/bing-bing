    알림    회원마다 고름 — 🔔 앱 알림 / 📅 달력 / 필요 없음

`?s=` 뒤가 회장님 시트로 가는 열쇠라서 **저장소에는 절대 적지 않습니다** (공개 저장소).

처음 한 번만 아래를 따라 해 주시면 됩니다. 20분쯤, PC 에서 하시는 게 편합니다.

## 1. 구글 시트 만들기

**왜** — 기록이 쌓일 곳입니다. 앱이 잘못돼도 이 시트를 열면 누가 언제 읽었는지 다 보입니다.

1. sheets.google.com 에서 **빈 스프레드시트** 를 만들고 제목을 `여전도회 성경통독` 으로.

## 2. 코드 붙여넣기

1. 시트 메뉴 **확장 프로그램 → Apps Script**. 새 창이 열립니다.
2. 왼쪽 `Code.gs` 안의 글을 **전부 지우고**, 저장소의
   [`bible-reading/dist/Code.gs`](dist/Code.gs) 내용을 통째로 붙여넣습니다
   (GitHub 에서 파일을 열고 오른쪽 위 **복사 아이콘**). 
3. 위의 **저장(디스크 모양)**.

## 3. 배포 — 열쇠(배포 아이디) 받기

1. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴 → **웹 앱**.
2. **다음 사용자 인증 정보로 실행: 나** / **액세스 권한이 있는 사용자: 모든 사용자**
   (그래야 회원들이 로그인 없이 씁니다)
3. **배포** → "액세스 승인" → 회장님 계정 → "확인되지 않은 앱" 이 나오면
   **고급 → (안전하지 않음)으로 이동 → 허용**. 회장님이 직접 넣은 코드라 구글이 심사하지 않았다는 뜻입니다.
4. 나온 **웹 앱 URL** 에서 `/s/` 와 `/exec` 사이가 **배포 아이디** 입니다.
   `https://script.google.com/macros/s/AKfy……xyz/exec` → `AKfy……xyz`

## 4. 앱 알림 켜기 (🔔 를 쓸 경우)

**왜** — 알림 열쇠를 만들고 "매일 아침 6시에 보내기" 를 예약합니다.

1. 앱스 스크립트 편집기 위쪽 함수 고르는 칸에서 **`setupPush`** 를 고르고 **▶ 실행**.
2. 권한을 다시 물으면 허용 (외부로 요청 보내기, 예약 실행).
3. 아래 **실행 로그** 에 `알림 준비 끝. 매일 아침 6시 무렵 …` 이 나오면 됩니다.
   - 열쇠는 '프로젝트 설정 → 스크립트 속성' 에만 들어갑니다. **`VAPID_PRIVATE` 은 지우거나 바꾸지 마세요** —
     바꾸면 이미 알림을 켠 휴대폰이 전부 끊깁니다.
   - 구글 예약 실행은 "6시 무렵" (앞뒤 15분쯤) 입니다. 정각은 아닙니다.

안 켜면 앱에 "🔔 앱 알림은 회장님이 준비 중이에요" 가 나오고 달력 알림만 됩니다.

## 5. 화면 띄우기 — 기본 브랜치에 머지

화면 파일은 저장소 `bible/` 폴더입니다. GitHub Pages 는 **기본 브랜치**에서만 뜨므로,
이 작업 브랜치를 기본 브랜치에 머지해야 `https://bing00179.github.io/bing-bing/bible/` 이 열립니다
(CLAUDE.md §13 과 같은 절차. 머지 후 영어 발음 앱 파일이 그대로인지 확인).

## 6. 확인하고 단톡방에 올리기

1. `https://bing00179.github.io/bing-bing/bible/?s=배포아이디` 를 회장님 휴대폰에서 엽니다.
   "누구세요?" 가 나오면 성공. 이름을 등록하고 시트의 **회원** 탭에 이름이 생겼는지 봅니다.
2. **알림은 꼭 두 대로 먼저 시험** — 아직 실제 휴대폰에서 확인하지 못했습니다.
   - 갤럭시(크롬): [🔔 앱 알림 받기] → 허용 → 시트 **알림** 탭에 줄이 생김 → 다음날 6시 무렵 알림
   - 아이폰(iOS 16.4 이상, Safari): 공유 버튼 → **홈 화면에 추가** → 홈 화면 아이콘으로 열기 →
     이름 다시 고르기 → [🔔 앱 알림 받기] → 허용 → 다음날 알림
   - 📅 달력: [내 달력에 넣기] → 달력에 들어가는지, 6시에 울리는지
   - 기다리기 싫으면 앱스 스크립트에서 **`sendMorning`** 을 ▶ 실행하면 바로 한 번 보냅니다
     (2027-01-01 전에는 보내지 않으므로 그 전에는 시험이 안 됩니다).
3. 괜찮으면 링크를 단톡방에 올립니다.

## 알아 두실 것

- 아이폰은 **홈 화면에 추가한 앱에서만** 앱 알림이 됩니다 (Safari 탭에서는 안 됨).
  홈 화면 앱은 Safari 와 저장 공간이 따로라서 처음에 이름을 한 번 더 고릅니다.
- 카톡 안 브라우저에서는 앱 알림·달력이 안 될 수 있습니다 → ⋮ → 다른 브라우저로 열기.
- 구글 캘린더는 가져온 일정의 알림 대신 그 달력의 기본 알림을 쓸 수 있습니다 (기억이라 확인 필요).
- 링크를 아는 사람은 누구나 이름을 등록·체크할 수 있습니다. 링크는 단톡방에만.

## 시트 읽는 법 — 전부 지우지 않고 덧쌓기만

| 탭 | 칸 | 뜻 |
|---|---|---|
| 회원 | 이름 · 등록 시각 | 등록 순서 = 함께 읽기 화면 순서. 잘못 등록한 이름은 이 줄을 지우면 명단에서 빠짐 |
| 기록 | 시각 · 이름 · 날짜 · 동작 | `완료`/`취소`. 같은 사람·같은 날짜는 **맨 아래 줄**이 지금 상태 |
| 알림 | 시각 · 이름 · 알림 주소 · 동작 | `등록`/`해제`/`만료`(앱을 지운 휴대폰). 주소별 맨 아래 줄이 지금 상태 |

## 화면

- **오늘** — 오늘 읽을 곳, 장별 말씀 링크, [읽기 완료], 아침 알림 고르기, 내 진도율, 밀린 날(빨강, 0일이면 안 보임)
- **함께 읽기** — 모두의 오늘 ✅, 밀린 날, 어디까지, 진도율
- **지난 날** — 날짜를 눌러 몰아 읽은 날 체크(안 읽은 날은 빨강), 📖 로 그날 말씀 링크
- **말씀** — 그날 장마다 **[📖 창세기 7장]** 버튼. 누르면 대한성서공회 웹사이트의 **개역개정** 그 장이 열립니다.
  개역개정은 저작권이 있어 본문을 앱에 넣지 않고 링크만 둡니다 (개역한글은 혼선 때문에 넣지 않음, 2026-11-11).
  링크 주소는 창세기·에스겔·요한복음·요한일서 4권만 확인했습니다 — **몇 권 눌러 보고 엉뚱한 장이 열리면 알려 주세요.**

계산: 진도율 = 완료한 날 장 수 합 ÷ 1,189 / 밀린 날 = 1월 1일 ~ **어제** 중 완료 안 한 날

## 코드를 고칠 때 (개발용)

    node bible-reading/build.js                 # dist/Code.gs 와 bible/ 다시 만들기
    node --test bible-reading/test/*.test.js    # 시험
    # 미리보기: python3 -m http.server 로 저장소를 띄우고
    #   /bible/?s=preview&today=2027-01-05   (가짜 서버, &vapid=x 면 🔔 버튼도 보임)

| 파일 | 하는 일 |
|---|---|
| `core.js` | 읽기표·진도율·밀린 날·달력 파일·개역개정 링크 (화면·서버·알림이 같이 씀) |
| `webpush.js` | 알림 서명(ES256) — 앱스 스크립트에 없어서 직접 구현, 시험이 node 암호 모듈로 검증 |
| `server.gs` | 시트 기록, 아침 알림 보내기 |
| `web/` | 화면(`index.html`, `api.js`), 알림 받는 곳(`sw.js`), 홈 화면 앱 정보 |

서버를 고치면 dist/Code.gs 를 다시 붙여넣고 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**.
새 배포를 만들면 배포 아이디가 바뀌어 단톡방 링크가 깨집니다.
