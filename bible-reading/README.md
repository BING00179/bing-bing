# 함께 읽는 성경 — 설치 안내

여전도회 성경 1년 1독 앱입니다. 2027-01-01 창세기 1장에서 시작해
2027-12-28 요한계시록 22장에서 끝납니다. 평일·토요일·공휴일 3장, 주일 5장.

회원은 카톡 링크를 눌러 로그인 없이 들어오고, 기록은 **회장님 구글 시트**에
한 줄씩 쌓입니다(지워지지 않음). 처음 한 번만 아래를 따라 해 주시면 됩니다.
10분쯤 걸립니다. PC 에서 하시는 게 편합니다.

## 1. 구글 시트 만들기

**왜** — 기록이 쌓일 곳입니다. 앱이 잘못돼도 이 시트를 열면 누가 언제 읽었는지 다 보입니다.

1. sheets.google.com 에서 **빈 스프레드시트** 를 만듭니다.
2. 왼쪽 위 제목을 `여전도회 성경통독` 으로 바꿉니다.

## 2. 코드 붙여넣기

**왜** — 시트에 "앱 화면" 과 "기록하는 일" 을 붙이는 단계입니다.

1. 시트 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다. 새 창이 열립니다.
2. 왼쪽 `Code.gs` 가 열려 있습니다. 안의 글을 **전부 지우고**,
   저장소의 [`bible-reading/dist/Code.gs`](dist/Code.gs) 내용을 통째로 붙여넣습니다.
   (GitHub 에서 파일을 열고 오른쪽 위 **복사 아이콘** 을 누르면 전체가 복사됩니다.)
3. 왼쪽 **파일 옆 +** → **HTML** 을 누르고 이름을 정확히 `Index` 로 적습니다
   (대문자 I, `.html` 은 자동으로 붙음).
4. 새로 생긴 `Index.html` 안의 글을 전부 지우고 [`dist/Index.html`](dist/Index.html) 내용을 붙여넣습니다.
5. 위의 **저장(디스크 모양)** 을 누릅니다.

## 3. 배포 — 앱 주소 받기

1. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 톱니바퀴 → **웹 앱** 을 고릅니다.
3. 이렇게 맞춥니다.
   - 설명: `성경통독`
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**  ← 이래야 회원들이 로그인 없이 들어옵니다
4. **배포** 를 누르면 "액세스 승인" 이 나옵니다. 회장님 구글 계정을 고르고,
   "확인되지 않은 앱" 경고가 나오면 **고급 → (안전하지 않음)으로 이동 → 허용**.
   회장님이 직접 만든 코드라서 구글이 심사하지 않았다는 뜻입니다.
5. **웹 앱 URL** (`https://script.google.com/macros/s/...` 로 시작)을 복사합니다.

## 4. 확인하고 카톡방에 올리기

1. 그 주소를 회장님 휴대폰에서 열어 봅니다. "누구세요?" 화면이 나오면 성공입니다.
2. 이름을 등록해 보고, 시트로 돌아가 **회원** 탭에 이름이 생겼는지 봅니다.
3. 괜찮으면 주소를 여전도회 단톡방에 올립니다.
   "링크 누르고 내 이름 등록 → 매일 읽고 [읽기 완료] 누르기" 면 됩니다.

⚠️ 이 주소는 **단톡방에만** 올려 주세요. 저장소(GitHub)는 공개라서 여기에는 적지 않습니다.
주소를 아는 사람은 누구나 이름을 등록하고 체크할 수 있습니다.

## 5. 아침 6시 알림 — 꼭 두 대로 먼저 시험

앱 '오늘' 화면에 **📅 매일 아침 6시에 알림 받기 → [달력에 넣기]** 가 있습니다.
누르면 362일치 일정 파일(bible-2027.ics)이 열리고, 휴대폰 달력에 넣으면
매일 06:00 에 "📖 창세기 1~3장" 같은 알림이 옵니다. 알림 메모의 링크를 누르면 앱이 열립니다.

⚠️ **실제 휴대폰에서는 아직 확인하지 못했습니다.** 단톡방에 알리기 전에
회장님 폰과 **아이폰 하나·갤럭시 하나**로 먼저 해 보세요.

- 아이폰: Safari 에서 눌러 "모두 추가" 가 나오는지, 다음날 6시에 알림이 오는지
- 갤럭시: 내려받은 파일을 눌러 삼성 캘린더(또는 구글 캘린더)로 가져와지는지, 알림이 오는지
- 카톡 안 브라우저에서는 파일이 안 열릴 수 있습니다 → ⋮ → 다른 브라우저로 열기
- 구글 캘린더는 가져온 일정의 알림을 무시하고 **그 달력의 기본 알림**을 쓸 수 있습니다
  (기억이라 확인이 필요합니다). 알림이 안 오면 이 경우일 가능성이 큽니다.

잘못 넣었으면 달력에서 '함께 읽는 성경' 일정을 지우면 됩니다.

## 시트 읽는 법

| 탭 | 칸 | 뜻 |
|---|---|---|
| 회원 | 이름 · 등록 시각 | 등록한 순서대로. 함께 읽기 화면도 이 순서 |
| 기록 | 시각 · 이름 · 날짜 · 동작 | `완료` 또는 `취소`. 같은 사람·같은 날짜는 **맨 아래 줄**이 지금 상태 |

- 이름을 잘못 등록한 분이 있으면 **회원** 탭에서 그 줄을 지우면 명단에서 빠집니다.
  (그분의 기록 줄은 남아 있어 나중에 같은 이름으로 다시 등록하면 되살아납니다.)
- 기록 줄은 지우지 마세요. 잘못 누른 것은 앱에서 다시 누르면 `취소` 줄이 붙습니다.

## 화면

- **오늘** — 오늘 읽을 곳과 [읽기 완료] 버튼, 달력 알림 받기, 내 진도율, 밀린 날(빨간색, 0일이면 안 보임)
- **함께 읽기** — 모두의 오늘 ✅, 밀린 날, 어디까지, 진도율
- **지난 날** — 날짜를 눌러 몰아 읽은 날 체크. 안 읽은 날은 빨간색

계산 방법
- 진도율 = 완료한 날들의 장 수 합 ÷ 1,189
- 밀린 날 = 1월 1일부터 **어제까지** 중 완료 안 한 날 (오늘은 안 셈)

## 코드를 고칠 때 (개발용)

    node bible-reading/build.js                 # dist/ 다시 만들기
    node --test bible-reading/test/*.test.js    # 시험
    # 미리보기: dist/preview.html 을 브라우저로 열기 (가짜 서버, ?today=2027-01-05 로 날짜 바꾸기)

`core.js`(읽기표·계산), `server.gs`(시트), `app.html`(화면)을 고치고 build 를 돌린 뒤
dist 를 다시 붙여넣고 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**.
그래야 주소가 바뀌지 않습니다.
