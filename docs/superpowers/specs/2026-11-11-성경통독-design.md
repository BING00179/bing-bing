# 성경통독 앱 — 설계 (2026-11-11)

여전도회 회원들이 함께 쓰는 성경 1년 1독 앱. 주식 시스템과 무관하며
`bible-reading/` 폴더에 따로 둡니다.

## 무엇을 하는가 (사장님 말씀 그대로)

> 내가 오늘 읽을 부분 활성화되고, 읽기 완료하면, 리더가 읽은 거 확인되면 하는 거야.
> 강제성을 원하는 게 아니라서.

1. 앱을 열면 **오늘 읽을 부분**이 크게 보인다
2. 읽고 **[읽기 완료]** 를 누른다
3. 리더(그리고 앱을 연 누구나)는 **누가 읽었는지** 본다. 리더는 보기만 한다 (확인 도장 없음)

## 정해진 것

| 항목 | 값 | 누가 |
|---|---|---|
| 접속 | 카톡 링크, 로그인 없음 | 사장님 |
| 분량 | 평일·토요일·공휴일 3장, 주일 5장 | 교회 방식 |
| 시작 | 2027-01-01(금) 창세기 1장 | 사장님 |
| 끝 | 2027-12-28(화) 요한계시록 22장 (362일째, 마지막 날만 2장) | 계산 |
| 밀린 날 | 지난 날짜도 나중에 체크 가능 | 사장님 |
| 리더 | 보기만 | 사장님 |
| 분위기 | 순위는 없음. 밀린 날 수·빨간 표시는 넣음 (2026-11-11 사장님 "그 정도는 넣자") | 사장님 |

[계산] 끝나는 날: 2027-01-01 부터 하루씩 (주일 5, 그 밖 3) 더해 누적이
1,189 이상이 되는 날 = 2027-12-28, 누적 1,190 → 마지막 날은 2장만.
공휴일이 평일과 같은 3장이므로 공휴일 달력이 필요 없습니다.

## 화면 (휴대폰 한 장, 큰 글씨)

1. **이름 고르기** — 처음 한 번. 명단에서 고르거나 "처음이에요" 로 등록.
   이 휴대폰에 기억(localStorage). 아래에 "다른 이름으로" 링크.
2. **오늘** — "11월 11일(목) · 마태복음 3~5장" 크게, 그 아래 [읽기 완료].
   누르면 "읽었어요 ✅" 로 바뀌고 다시 누르면 취소.
   시작 전(2027-01-01 이전)에는 "1월 1일 창세기 1~3장으로 시작합니다" 안내만.
3. **함께 읽기** — 이름마다 오늘 ✅ 여부, **밀린 날 수**(빨간 글씨, 0이면 안 보임), "어디까지"(가장 최근에 완료한
   날의 분량 끝, 예: "이사야 12장까지"), **진도율 막대**. 순위 없음.
   이름은 등록 순서대로(진도율 순 정렬 안 함 — 강제성 없게).
   맨 위 '오늘' 화면에도 내 진도율 막대를 작게.

   **진도율** = 완료한 날들의 장 수 합 ÷ 1,189 × 100, 소수점 버림.
   예: 1월 1일~3일(3+3+5장) 완료 → 11 ÷ 1,189 = 0.9% → "0%" 가 아니라
   "11장 / 1,189장 (0.9%)" 처럼 장 수를 같이 보여 처음에도 움직이는 게 보이게.
   (기준: 성경 전체. '오늘까지 교회 진도 대비' 는 밀린 것처럼 보이므로 쓰지 않음.)
4. **지난 날** — 최근 날짜 목록에서 아무 날이나 눌러 완료/취소.
   **안 읽은 지난 날은 빨간색**, 완료한 날은 ✅. 오늘 화면에도
   "밀린 날 2일" 을 빨간 글씨로 작게(0이면 안 보임). 누르면 지난 날 목록으로.

   **밀린 날** = 시작일(2027-01-01)부터 **어제까지** 중 완료 안 한 날 수.
   오늘은 하루가 남았으므로 세지 않음. 나중에 체크하면 바로 줄어듦.
   시작 전·끝난 뒤(2027-12-28 이후)는 끝날까지만 셈.

## 만드는 방식 — 구글 시트 + 앱스 스크립트

- 앱 화면(HTML)과 서버 코드(`Code.gs`)가 같은 앱스 스크립트 프로젝트 안에 있음.
  "웹 앱으로 배포, 액세스: 모든 사용자" → 로그인 없는 주소가 나옴.
- 시트 두 장:
  - `회원`: 이름 | 등록 시각
  - `기록`: 시각 | 이름 | 날짜(YYYY-MM-DD) | 동작(완료/취소)
  - **지우지 않고 덧쌓기만** 함. 현재 상태 = 그 (이름, 날짜) 의 마지막 줄.
- 서버 함수: `getState()` (명단·기록 전부), `register(name)`, `mark(name, date, done)`.
  `LockService` 로 동시에 누를 때 줄이 꼬이지 않게.
- 이름 앞뒤 공백 제거, 20자 제한, 같은 이름은 새로 만들지 않고 그 이름으로 들어감.
- 미래 날짜는 체크 못 함(서버에서 거부). 날짜는 한국 시각 기준.

## 버린 방식

- Claude 공유 페이지: 로그아웃 상태에서는 기록 불가(설명서 "null if signed out") → 카톡 링크와 안 맞음
- GitHub Pages + Firebase: 설정이 하나 더 늘고 기록을 사장님이 직접 열어 보기 어려움

## 읽기표 코드

`plan.js` 하나: 66권 이름·장 수 표, `portionFor(date)` → {시작 권·장, 끝 권·장} 또는 null(시작 전/끝난 뒤).
앱 화면과 시험이 같은 파일을 씀.

## 시험 (node, 의존성 없음)

- 66권 장 수 합 = 1,189
- 2027 전체를 돌면 모든 장이 정확히 한 번씩, 순서대로 나옴 (빠짐·겹침 없음)
- 주일 분량 5장, 그 밖 3장 (마지막 날 제외)
- 2027-01-01 = 창세기 1~3장, 2027-12-28 = 요한계시록 21~22장, 그 다음 날 = null
- 2026-12-31 = null
- 밀린 날: 오늘은 안 셈, 어제는 셈, 시작 전 0, 나중에 체크하면 줄어듦, 12-28 넘으면 더 안 늘어남
- 진도율: 완료 날짜 집합 → 장 수 합 (취소된 날 제외, 같은 날 두 번 완료해도 한 번)
