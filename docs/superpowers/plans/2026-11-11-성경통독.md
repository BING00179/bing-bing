# 성경통독 앱 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 여전도회가 카톡 링크로 함께 쓰는 1년 1독 체크 앱 (설계: `docs/superpowers/specs/2026-11-11-성경통독-design.md`)

**Architecture:** 순수 로직 `core.js` 하나를 화면(브라우저)·서버(앱스 스크립트)·시험(node)이 같이 씀.
`build.js` 가 `core.js` 를 끼워 넣어 붙여넣기용 파일 두 개(`dist/Code.gs`, `dist/Index.html`)와
가짜 서버를 단 미리보기(`dist/preview.html`)를 만든다.

**Tech Stack:** 순수 JS(ES2017, 의존성 없음), Google Apps Script(V8) + 구글 시트, `node --test`.

## Global Constraints

- 분량: 주일 5장, 그 밖(평일·토·공휴일) 3장. 시작 2027-01-01, 끝 2027-12-28(마지막 날 2장)
- 날짜는 'YYYY-MM-DD' 문자열, 한국 시각 기준. 미래 날짜 체크 금지(서버)
- 밀린 날 = 시작일~어제 중 미완료 날 수(오늘 제외, 끝날 이후 안 늘어남). 0이면 안 보임, 있으면 빨강
- 진도율 = 완료한 날 장 수 합 / 1,189, "11장 / 1,189장 (0.9%)"
- 순위·정렬 없음 — 명단은 등록 순서
- 시트 기록은 덧쌓기만(완료/취소 줄). 상태 = (이름, 날짜)의 마지막 줄
- 저장소 공개: 시트·배포 주소를 코드에 넣지 않음

## Task 1: core.js 읽기표

시험 먼저 (`node --test bible-reading/test`):
- 66권, 장 수 합 1,189
- `portionFor('2026-12-31') === null`, `portionFor('2027-12-29') === null`
- `portionFor('2027-01-01')` → 창세기 1~3, `portionFor('2027-01-03')`(주일) → 창세기 7~11
- 2027-01-01~12-28 을 돌며 모든 장이 정확히 한 번씩 순서대로 (빠짐·겹침 없음)
- 마지막 날 → 요한계시록 21~22, 주일 5장·그 밖 3장(마지막 날 제외)
- `portionLabel`: 한 권 안 "창세기 1~3장", 한 장 "오바댜 1장", 권을 넘으면 "창세기 50장 ~ 출애굽기 2장"

## Task 2: core.js 기록 → 상태

- `doneSet(records, name)`: records = [[이름, 날짜, '완료'|'취소'], ...] 순서대로, 마지막 줄 기준
- `progress(dates)` → {chapters, percent(소수 1자리 버림)}; 1/1~1/3 → 11장, 0.9
- `missedDays(dates, today)`: 오늘 제외, 시작 전 0, 끝 이후 고정(362 - 완료)
- `lastReadLabel(dates)`: 가장 늦은 완료 날 분량 끝 "이사야 12장까지", 없으면 ''
- `validName`: 앞뒤 공백 제거, 1~20자, 아니면 null

## Task 3: server.gs + app.html + build.js

- build 시험: dist/Code.gs 와 Index.html 에 core 본문 포함, `/*CORE*/` 남지 않음, `docs.google.com`/`script.google.com/macros/s/` 문자열 없음
- preview.html 을 Playwright 로 폰 폭(390px) 열어 이름 등록 → 완료 → 함께 읽기 ✅·진도율·밀린 날 빨강 확인 (가짜 오늘 2027-01-05)
