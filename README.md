# 📖 매일 영어 단어장

매일 영어 단어를 입력하면 **원어민 발음으로 읽어주고**, 브라우저에 **날짜별로 저장**되는 단어장입니다.

영한 사전이 안에 들어 있어 **뜻이 자동으로 채워지고, 한글로도 영어 단어를 찾을 수 있습니다.** 서버도 회원가입도 API 키도 필요 없습니다.

## 시작하기

`index.html` 파일을 더블클릭해서 브라우저로 열면 끝입니다. (홈 화면에 앱으로 설치하려면 아래 [홈 화면에 앱으로 설치하기](#-홈-화면에-앱으로-설치하기)를 보세요.)

> 발음 재생은 브라우저에 내장된 음성 합성(Web Speech API)을 사용합니다.
> **Chrome · Edge · Safari**를 권장합니다.
> 인터넷 없이도 동작합니다 (연결이 없으면 글꼴만 시스템 기본 글꼴로 대체됩니다).

## 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 단어 저장 | 단어를 입력하고 **저장** 또는 `Enter` — 뜻이 자동으로 채워지고, 저장과 동시에 발음이 나옵니다 |
| 뜻 확인 | 영어 단어를 치면 아래에 **내장 사전의 뜻**이 바로 뜹니다 |
| 한글로 영어 찾기 | 입력창에 `행운`처럼 **한글을 치면** 그 뜻을 가진 영어 단어가 추천됩니다. 고르면 발음이 바로 나오고, 그대로 저장하면 영어 단어로 저장됩니다 |
| 발음만 미리 듣기 | 단어를 입력하고 **🔊 듣기** |
| 저장한 단어 다시 듣기 | 목록에서 단어를 클릭하거나 **🔊** 버튼 |
| 오늘 공부한 단어 복습 | 앱을 열면 나오는 `최근 10단어`에서 **📚 최근 10단어 듣기** |
| 단계별로 공부 | 목록 위 탭에서 **초등 · 중등 · 고등 · 토익토플**을 고르면 그 단계로 바뀝니다 |
| 단어 찾기 | 검색창에 단어나 뜻을 입력 (한글로도, 어느 탭에서도 됩니다) |
| 삭제 | 항목의 **🗑** 버튼 |

### ⚙️ 발음 설정

- **목소리**: 기기에 설치된 **미국식(en-US) 원어민 목소리** 중에서 고릅니다. 미국식 목소리가 없는 기기에서만 다른 영어 목소리로 대신 재생하고, 그 사실을 알려 줍니다.
- **말하기 속도**: 0.5배 ~ 1.3배 — 받아쓰기 연습할 때 느리게 두면 좋습니다
- **저장할 때 자동으로 발음**: 꺼두면 저장만 조용히 됩니다

### 🎧 듣기 퀴즈

**지금 고른 탭**의 단어 중 하나를 무작위로 읽어줍니다. 들리는 대로 받아쓰고 **확인**을 누르면 채점되고, 점수가 누적됩니다. 잘 안 들리면 **🔊 다시**를 누르세요.

### 🎯 하루 목표 (기본 10단어)

하루에 10단어씩 쌓는 것을 기준으로 맞춰 두었습니다.

- 가운데 칸이 `오늘 / 10단어`로 바뀌고, 담을 때마다 아래 막대가 찹니다.
- 단계 탭의 담기 버튼이 **＋ 오늘 남은 7개 담기**처럼 남은 개수를 알려 주고, 누르면 딱 그만큼만 담깁니다.
- 목표를 채우면 숫자 옆에 ✓가 붙고 하루에 한 번 축하 문구가 뜹니다.
- `⚙️ 발음 설정`의 **하루 목표**에서 5 · 10 · 15 · 20 · 30단어로 바꿀 수 있습니다.

### 📊 상단 숫자

- **전체 단어** — 지금까지 저장한 단어 수
- **오늘 / 10단어** — 오늘 담은 수와 하루 목표. 아래 막대가 채워지고, 목표를 채우면 숫자 옆에 ✓가 붙습니다
- **연속 학습일** — 하루도 빠지지 않고 단어를 저장한 날의 연속 일수

## 📚 내장 영한 사전

영어 단어 **2,593개**가 앱 안에 들어 있습니다. 인터넷 없이 동작하고, 따로 설정할 것이 없습니다. 철자는 **미국식으로 통일**했습니다.

| 단계 | 단어 수 | 내용 |
|---|---|---|
| 초등 필수 | 403 | 동물·몸·가족·음식·색깔·기본 동사 등 |
| 중등 필수 | 1,387 | 학교 영어의 중심이 되는 일반 어휘 |
| 고등 필수 | 406 | 추상어·독해용 어휘 |
| 토익·토플 | 494 | 비즈니스(계약·회계·물류·인사) + 학술(연구·통계·논증) 어휘 |

목록 위의 탭에서 단계를 고르면 **그 단계가 활성화되어 화면 전체가 그 단어로 바뀝니다.**

```
[ 최근 10단어 ] [ 내 단어장 24 ] [ 초등 403 ] [ 중등 1387 ] [ 고등 406 ] [ 토익토플 494 ]
```

**앱을 열면 언제나 `최근 10단어`부터 보입니다.** 가장 최근에 담은 단어가 맨 위로 오고, 하루 목표만큼(기본 10개) 모아서 보여 줍니다. 여기서 바로 듣고 퀴즈를 풀면 그날 공부가 끝납니다. 단계 탭을 보다가 단어를 저장하면 자동으로 이 화면으로 돌아옵니다.

- 단계 탭을 고르면 그 단계 단어가 목록에 뜹니다. 🔊로 발음을 듣고, ＋로 내 단어장에 담습니다. 이미 담은 단어는 ✓로 표시됩니다.
- **＋ 오늘 남은 N개 담기**를 누르면 하루 목표까지 남은 만큼 아직 안 담은 단어가 한 번에 들어옵니다.
- **🔊 이 화면 듣기**는 지금 보이는 단어를 순서대로 읽어 줍니다.
- **듣기 퀴즈도 활성화된 탭을 따라갑니다.** 토익토플 탭을 골라 두면 토익 단어로만 출제됩니다.
- 고른 탭은 저장되어, 앱을 다시 열어도 그 단계에서 이어집니다.
- `내 단어장` 탭은 예전처럼 **내가 담은 단어를 날짜별로** 보여 줍니다.

> 한 단어가 여러 단계에 속할 수 있습니다. 예를 들어 `schedule`은 `중등 · 토익토플`입니다.

- **영어 → 뜻**: `pronunciation`을 치면 `pronunciation 〈명〉 발음`이 뜨고, 뜻 칸이 자동으로 채워집니다. 뜻을 직접 고쳐 쓰면 그 내용이 우선합니다.
- **한글 → 영어**: `행운`을 치면 `fortune`, `luck`이 추천됩니다. `↓` `↑` 키나 손가락으로 고르면 됩니다.
- **부분 검색**: `prom`만 쳐도 `prompt`, `promise`, `promote`가 나옵니다.
- 사전에 없는 단어도 그대로 저장하고 발음을 들을 수 있습니다. 뜻만 비어 있을 뿐입니다.

### 사전에 단어 더 넣기

`dictionary.js`를 열어 목록에 한 줄씩 추가하면 됩니다. 순서는 상관없습니다.

```
serendipity|n|뜻밖의 행운|h
```

`단어|품사|뜻|단계` 형식입니다. 단계는 `e`(초등) `m`(중등) `h`(고등) `t`(토익토플)이고, 여러 단계에 넣으려면 `mt`처럼 이어 씁니다. 품사는 `n`(명사) `v`(동사) `a`(형용사) `ad`(부사) `prep`(전치사) `conj`(접속사) `pron`(대명사) `int`(감탄사) `num`(수사)입니다.

### 인터넷 사전 (선택, 기본 꺼짐)

`⚙️ 발음 설정`에서 켜면, **내장 사전에서 못 찾은 단어만** 무료 번역 서비스(MyMemory)로 보내 뜻을 받아옵니다. 꺼 두면 입력한 내용은 어디로도 전송되지 않습니다.


## 태블릿 · 스마트폰에서 쓰기

브라우저만 있으면 iPad, 안드로이드 태블릿, 폰에서 그대로 동작합니다. 터치 기기에 맞춰 다음이 적용돼 있습니다.

- 입력창을 눌러도 화면이 확대되지 않고(16px 글자), 버튼은 손가락에 맞는 크기(44px 이상)입니다.
- 영어 입력창은 **자동 대문자·자동 수정이 꺼져 있어** `serendipity`가 멋대로 바뀌지 않습니다.
- 페이지를 열자마자 키보드가 튀어나오지 않습니다. 입력창을 눌렀을 때만 올라옵니다.
- iOS는 첫 화면 터치가 있어야 소리를 허용하므로, 화면을 한 번 누른 뒤부터 발음이 재생됩니다.

**홈 화면에 추가**하면 앱처럼 전체 화면으로 열립니다.

- iPad · iPhone (Safari): 공유 버튼 → `홈 화면에 추가`
- 안드로이드 (Chrome): 우측 상단 ⋮ → `홈 화면에 추가`

> 소리가 나오지 않으면 기기의 **무음 스위치**와 **볼륨**을 먼저 확인하세요.
> iPad는 `설정 → 손쉬운 사용 → 음성 콘텐츠`에서 영어 음성을 추가로 내려받으면 발음 품질이 좋아집니다.


## 📥 파일 하나로 쓰기 (standalone.html)

`standalone.html` 은 **사전까지 전부 들어 있는 파일 하나**입니다. 이 파일만 있으면 됩니다.

- PC·노트북: 더블클릭 → 브라우저에서 바로 열립니다. 인터넷도 필요 없습니다.
- iPad·안드로이드: `파일` 앱에 저장해 두고 브라우저로 열면 됩니다.
- 단어는 그 브라우저에 그대로 저장되고, 새로고침해도 남아 있습니다.

> 홈 화면 설치와 오프라인 캐시는 인터넷 주소(https)가 있어야 동작하므로, `standalone.html` 에서는 빠져 있습니다. 앱처럼 설치하려면 아래 [홈 화면에 앱으로 설치하기](#-홈-화면에-앱으로-설치하기)를 보세요.

`index.html` 이나 `dictionary.js` 를 고친 뒤에는 아래 명령으로 다시 만듭니다.

```
python3 build-single.py
```


## 📱 홈 화면에 앱으로 설치하기

이 앱은 **PWA**라서 홈 화면에 설치하면 주소창 없이 앱처럼 열리고, 인터넷이 없어도 동작합니다.

### 1단계 — 인터넷 주소 만들기 (GitHub Pages, 한 번만)

> GitHub Pages는 **공개(public) 저장소에서 무료**입니다. 이 저장소가 비공개라면 `Settings → General → 맨 아래 Danger Zone → Change visibility → Make public`으로 공개로 바꾸거나, GitHub Pro 이상 플랜이 필요합니다.

브라우저에서 이 저장소를 열고 (태블릿에서도 됩니다):

1. **Settings** 탭 → 왼쪽 메뉴에서 **Pages**
2. `Source`를 **Deploy from a branch**로 두고, `Branch`에서 이 앱이 올라간 브랜치와 `/ (root)`를 고른 뒤 **Save**
3. 1~2분 뒤 페이지 위쪽에 나오는 주소(`https://<사용자이름>.github.io/<저장소이름>/`)가 앱 주소입니다

### 2단계 — 홈 화면에 추가

그 주소를 폰·태블릿 브라우저로 열고,

- **iPad · iPhone (Safari)**: 공유 버튼 <kbd>􀈂</kbd> → `홈 화면에 추가` → `추가`
- **안드로이드 (Chrome)**: 주소창의 설치 아이콘, 또는 우측 상단 ⋮ → `앱 설치` / `홈 화면에 추가`

이제 홈 화면 아이콘을 누르면 전체 화면으로 열리고, 비행기 모드에서도 단어를 넣고 발음을 들을 수 있습니다.

> 앱 파일을 고친 뒤에는 `sw.js` 맨 위의 `CACHE = "eng-words-v1"` 숫자를 올려 주세요. 그래야 설치된 기기가 새 버전을 받아 갑니다.


## 저장 위치와 백업

단어는 **브라우저의 localStorage**에 저장됩니다. 브라우저를 닫거나 컴퓨터를 껐다 켜도 그대로 남아 있습니다.

다만 다음의 경우에는 데이터가 사라질 수 있으니 가끔 백업해 두세요.

- 브라우저의 "인터넷 사용 기록 / 사이트 데이터 삭제"를 실행한 경우
- 시크릿(비공개) 모드로 사용한 경우
- 다른 브라우저나 다른 기기에서 연 경우 (기기 간에 자동으로 동기화되지 않습니다)

**백업 방법** — `⚙️ 발음 설정 · 내보내기`를 열고

- **내보내기(복사)** : 전체 단어가 JSON으로 복사됩니다. 메모장 등에 붙여넣어 보관하세요.
- **가져오기** : 백업해 둔 JSON을 상자에 붙여넣고 누르면 복원됩니다. 이미 있는 단어는 건너뛰므로, 다른 기기의 단어를 합칠 때도 쓸 수 있습니다.
- **CSV로 복사** : 엑셀·구글 시트에 바로 붙여넣을 수 있는 형식입니다.

## 기술 메모

- 순수 HTML/CSS/JavaScript. 빌드 도구도, 외부 라이브러리도 없습니다.
- 파일 구성: `index.html`(앱) · `dictionary.js`(영한 사전 2,593단어 · 단계 태그 포함) · `manifest.webmanifest`+`sw.js`+`icon-*.png`(홈 화면 설치·오프라인) · `standalone.html`(위 둘을 합친 단일 파일, `build-single.py` 로 생성)
- 사전 검색: 영어는 완전 일치 → 앞부분 일치 → 부분 일치, 한글은 뜻 일치 → 앞부분 → 부분 일치 순으로 정렬합니다.
- 발음: `SpeechSynthesis` API — `en-US` 목소리만 사용하고, 없는 기기에서만 다른 영어 목소리로 대체합니다.
- 저장: `localStorage` 키 `daily-english-words/v1`
- 글꼴: Newsreader(영어 단어) + IBM Plex Sans KR(한글 UI) + IBM Plex Mono(숫자), Google Fonts에서 불러오며 실패하면 시스템 글꼴로 대체됩니다.
- 터치 기기: `(pointer:coarse)` 미디어 쿼리로 입력창·버튼 크기를 키우고, iOS의 오디오 잠금은 첫 터치 시 무음 발화로 해제합니다.
- 다크 모드: 시스템 설정을 따르고, 우측 상단 🌗 버튼으로 직접 바꿀 수도 있습니다.
